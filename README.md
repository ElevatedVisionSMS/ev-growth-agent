# Elevated Vision AI Growth Agent — Test Version

Your AI marketing employee for local businesses.

This is a v0.1 client-side demo. Enter a business's basic info and get an AI-generated marketing growth report: SEO recommendations, a 30-day content calendar, review response drafts, blog ideas, social captions, homepage fixes, and a Marketing Health Score.

## Files
- `index.html` — the working demo app (open directly in a browser, or run as a Claude.ai artifact)
- `PRD.md` — product requirements doc: full vision, what's built, what's intentionally out of scope, and the roadmap to live scanning

## What this version does NOT do yet
No live scanning of the website, Google Business Profile, or social accounts — see "Not in this version" in PRD.md. The report is generated from the info the user types in.

## Roadmap
See PRD.md section 8 for the free/low-cost path to real website, GBP, and search scanning.
